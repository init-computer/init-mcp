# Security

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/init-computer/init/security/advisories/new), not public issues. We aim to acknowledge reports within two business days.

This covers the CLI, SDK and MCP server in this repo. Use the same channel for issues in the Init service, and we will route them.

If you've exposed an Init API key, rotate it right away in the [console](https://www.init.computer/console).
